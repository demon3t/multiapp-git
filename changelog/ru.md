# Изменения mGit

## 0.3.3

### New

- При первом запуске mGit предлагает включить автоматическую проверку обновлений.
- Кнопка «Обновить» открывает окно «Что нового» с изменениями со времени установленной версии.

### Improved

- В заголовке окна отображается ход скачивания и готовность новой версии к установке.

## 0.3.2

### New

- Пакетный экспорт подключений, датасетов, графиков, дашбордов и сохранённых запросов Superset.
- Команда восстановления из Git через адаптер и автоматическое скачивание обновлений для Windows x64.

### Fixed

- Superset принимает обновлённый формат метаданных снимка и очищенные параметры подключений.
