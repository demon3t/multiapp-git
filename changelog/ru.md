# Изменения mGit

## 0.3.4

### New

- История Git с графом веток и слияний, метками, списком файлов и просмотром diff выбранного коммита.
- Контекстное меню для коммитов с созданием веток и тегов, checkout, cherry-pick, revert, reset и rebase.
- Сравнение коммита с рабочей папкой, сохранение патча и копирование полного SHA коммита.
- Горячие клавиши для команд в меню «Файл», «Приложение» и «Обновления».

### Improved

- Компактная панель Git-операций и раскрываемые списки локальных и удалённых веток с вложенностью.
- Контекстные меню веток и коммитов работают с клавиатуры и используют единый стиль приложения.
- Новая иконка mGit и обновлённое окно «Что нового» с прогрессом скачивания.

## 0.3.3

### New

- При первом запуске mGit предлагает включить автоматическую проверку обновлений.
- Кнопка «Обновить» открывает окно «Что нового» с изменениями со времени установленной версии.

### Improved

- В заголовке окна отображается ход скачивания и готовность новой версии к установке.

## 0.3.2

### New

- Пакетный экспорт подключений, датасетов, графиков, дашбордов и сохранённых запросов Superset.
- Команда восстановления из Git через адаптер и автоматическое скачивание обновлений для Windows x64.

### Fixed

- Superset принимает обновлённый формат метаданных снимка и очищенные параметры подключений.
